# Timepick Daily

06:00부터 다음 날 06:00까지 하루를 10분 단위 타임블록으로 계획하고 완료 여부를 체크하는 웹 앱입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.

## MVP 기능

- 메인 화면에서 일정 완료/미완료 토글
- 편집 화면에서 Pointer Events 기반 드래그로 일정 생성
- 일정 생성 직후 이름 입력
- 기존 일정 우클릭 또는 길게 누르기로 이름 변경/삭제
- 일정 시간 중복 생성 방지
- 편집 내용을 draft로 관리하고 확인 시에만 반영
- `localStorage`를 사용해 새로고침 및 재접속 후에도 일정 유지

일정은 현재 브라우저에만 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터를 삭제하면 일정도 삭제됩니다.

Firebase 저장, 로그인, 기기 간 동기화는 향후 기능으로 유지합니다.
